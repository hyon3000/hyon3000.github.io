## Hwatu card faces (card/img/c0.webp ... c47.webp)
Korean-style hwatu (화투) artwork, Wikimedia Commons category "SVG Hwatu" (https://commons.wikimedia.org/wiki/Category:SVG_Hwatu).

- Artwork: Marcus Richert (https://commons.wikimedia.org/wiki/File:Hwatu_overview.svg), made on the basis of Louie Mantia, Jr.'s Hanafuda graphics (also on Wikimedia Commons); colours changed and some linework redrawn to resemble a typical Korean hwatu deck.
- Individual card files extracted and optimized by Spenĉjo (https://commons.wikimedia.org/wiki/User:Spen%C4%89jo), e.g. https://commons.wikimedia.org/wiki/File:Hwatu_January_Hikari.svg
- Licence: Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0), https://creativecommons.org/licenses/by-sa/4.0/
- Changes made here: the SVG files were rasterised to 156x254 px WebP (one file per card, no other change); a small class label is drawn over each card by the page (switchable with the "Labels" button). These images stay under CC BY-SA 4.0.

File mapping (card id = month*4 + k): 1,3: Hikari, Tanzaku, Kasu 1, Kasu 2; 2,4,5,6,7,9,10: Tane, Tanzaku, Kasu 1, Kasu 2; 8: Hikari, Tane, Kasu 1, Kasu 2; 11: Hikari, Kasu 2 (double junk), Kasu 1, Kasu 3; 12: Hikari, Tane, Tanzaku, Kasu (double junk).
